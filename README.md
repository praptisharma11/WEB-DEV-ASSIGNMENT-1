# Personal Portfolio Website

## Project Description

This project is a simple personal portfolio website created as a college assignment. The website is developed using only HTML and demonstrates the basic concepts of HTML structure and web page design.

## Objective

The main objective of this project is to create a basic portfolio webpage that presents personal and academic information in a structured manner.

## Technologies Used

* HTML5

## Features

* Introduction/About Me section
* Education details
* Skills section
* Projects section
* Contact information
* Simple and structured webpage layout
