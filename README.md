
# Personal Portfolio Website - Prapti Sharma

## Project Overview

This is my personal portfolio website created using HTML5 and CSS3.
The website provides information about me, my technical skills,
educational background, projects, and contact details.

This project is an improved version of my previous Lab 2 portfolio.
In this version, I have used modern CSS concepts such as Flexbox,
CSS Grid, responsive design, transitions, transforms, and animations
to make the website more attractive and user-friendly.

## Technologies Used

- HTML5 - For creating the structure of the website.

- Google Fonts - For modern typography.
- Flexbox - For arranging and aligning elements.
- CSS Grid - For displaying skills, projects, and education cards.

## CSS Concepts Implemented

### 1. Flexbox
Used display: flex to arrange elements in the header and hero section.
It helps align the navigation links, introduction, and profile image.

### 2. CSS Grid
Used display: grid to arrange skill cards, project cards, and
education cards in rows and columns.

### 3. Responsive Web Design
Used media queries to adjust the layout for different screen sizes.

- Desktop: Multiple columns for cards.
- Tablet: Two-column card layouts.
- Mobile: Single-column card layouts.

### 4. Relative CSS Units
Used flexible units such as:
- rem
- %
- vw
- clamp()

These units help make the website adaptable to different screen sizes.

### 5. Hover Effects
Added hover effects to navigation links, buttons, project cards,
skill cards, education cards, and the profile image.

### 6. CSS Transitions
Used transition properties to make hover effects smooth.

### 7. CSS Animations
Used @keyframes to create:
- Color-changing animation for Full Stack Developer text.
- Fade-in animation for website sections.

### 8. CSS Transforms
Used transform properties such as translateY() and scale()
to create interactive movement and scaling effects.
